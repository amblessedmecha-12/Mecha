# Chi's Haven

A modern and responsive landing page website for Chi's Haven.

## About

Chi's Haven is a website designed to showcase the brand, services, images, and social media platforms while providing an easy way for visitors to make contact through WhatsApp.

## Features

* Responsive design for mobile and desktop
* Modern landing page
* Image sections
* Social media links
* WhatsApp contact button
* Hover animations
* Simple and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
chi's-haven/
├── index.html
├── style.css
├── script.js
├── images/
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
